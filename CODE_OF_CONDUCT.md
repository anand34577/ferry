# Code of Conduct

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, welcome newcomers, and keep discussions about the work.
Harassment, discrimination and personal attacks are not tolerated.

Report unacceptable behaviour privately to the maintainers (via a private GitHub security advisory or the contact
listed on the maintainers' profiles). Reports are handled confidentially.
