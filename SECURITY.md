# Security policy

**Please do not report security vulnerabilities through public GitHub issues.**

Report privately via GitHub's *Security → Report a vulnerability* (private advisory) for this repository.
Include affected version, steps to reproduce and impact. We aim to acknowledge within 3 days and to ship a fix
or mitigation for confirmed issues within 30 days, coordinating disclosure with you and crediting you if you wish.

Supported versions: the latest minor release receives security fixes.

Scope includes the server, web app, Android app and the LAN protocol (e.g. accepting files without consent,
link access after revocation, path traversal, authentication bypass, credential leaks in logs).
